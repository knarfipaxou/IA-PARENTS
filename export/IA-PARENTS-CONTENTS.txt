IA-PARENTS — archive complète pour Cloud Design
================================================

Fichier : IA-PARENTS-full-for-design.zip
Taille  : 5.6 Mo
Fichiers: 320

OUI — les visuels sont inclus :
- assets/icons/     : icônes UI (nav, scan, trophée…)
- assets/home/      : tuiles accueil clair/sombre
- assets/subjects/  : icônes matières (clair/sombre)
- assets/sounds/    : sons feedback
- design/project/   : prototypes HTML Claude Design + captures
- design/chats/     : historique design

Code inclus (pour comprendre la structure des écrans) :
- app/              : écrans Expo Router
- components/       : UI (Btn, Card, TopBar…)
- constants/theme.ts: design tokens (couleurs, typo)
- design/           : maquettes HTML d'origine

Exclu volontairement (trop lourd / inutile pour le design) :
- node_modules/, .git/, builds iOS/Android

Pour Cloud Design / Figma :
1. Télécharge IA-PARENTS-full-for-design.zip
2. Dézippe
3. Importe surtout assets/ + design/project/
4. Lis constants/theme.ts et design/README.md pour les tokens
